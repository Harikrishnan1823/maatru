# மாற்று — Maatru
### "Speak yours. They hear theirs."

Maatru is a voice-first real-time Indian 
language translator app.

Speak anything naturally in your language.
Maatru instantly translates and speaks it
in the other person's language.

No typing. No fixed phrases. Just speak.

---

## Supported Languages (Phase 1)
- Tamil (தமிழ்)
- English
- Hindi (हिन्दी)
- Malayalam (മലയാളം)
- Telugu (తెలుగు)
- Kannada (ಕನ್ನಡ)

## Scenarios
- Hospital
- Travel
- Emergency
- Shopping
- Restaurant
- Daily Conversation
